# LOG-postech.github.io

News is maintained in `news.html`, newest first. The page initially shows 10
entries; each **Show more** click reveals up to 5 more. Without JavaScript,
all current entries remain readable. The home page displays the newest 5.

News from before 2026 is preserved in `_archive/news-before-2026.md` and is
not displayed on the website. Keep `_archive` out of any custom deployment;
GitHub Pages/Jekyll excludes underscore-prefixed directories by default.
